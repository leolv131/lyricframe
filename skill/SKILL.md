# LyricFrame · 词帧

Turn a song the user already has into an animated music video. You write Python that draws every
frame; nothing is generated by a video model. Default output: a 30–60 s 1920×1080 clip, then the full
song if they like it.

## First, set up the workspace (silently)

The folder this SKILL.md is in contains the whole LyricFrame toolkit (usually
`/mnt/skills/user/lyricframe` in the Claude app, `~/.claude/skills/lyricframe` in Claude Code,
`~/.agents/skills/lyricframe` in Codex). Skill folders can be read-only, so copy it and work in the copy:

```bash
SKILL_DIR=/mnt/skills/user/lyricframe          # the folder this SKILL.md was read from
[ -f "$SKILL_DIR/SKILL.md" ] || SKILL_DIR="$(dirname "$(find / -name SKILL.md -path '*lyricframe*' 2>/dev/null | head -1)")"
cp -r "$SKILL_DIR" ~/lyricframe && cd ~/lyricframe
pip install -r requirements.txt 2>/dev/null || pip install --break-system-packages -r requirements.txt
ffmpeg -version >/dev/null 2>&1 || echo "no ffmpeg: imageio-ffmpeg will be used"
```

Then **read `AGENTS.md` in that folder and follow it exactly** — it is the step-by-step director's
manual (gather → timing → story → one picture per line → storyboard → style test → build → check →
deliver), with the commands for every step. Full reasoning: `docs/en/workflow.md` (中文
`docs/zh/workflow.md`). Two finished projects to imitate: `examples/hudie`, `examples/gaobai-qiqiu`.
A ready-to-copy project: `templates/starter`.

## Rules that never bend

1. **Never write out or quote the lyrics.** Lyric text only moves between the user's `.lrc` and the
   scripts; you read `work/timing.json` (line numbers and times only) and refer to "line 7".
2. **Stop at each ✋ gate** in AGENTS.md and ask the user one plain question, with a picture (still,
   contact sheet, short preview) — unless they said "just make it".
3. **The main character must be readable in every shot at phone size.**
4. Invent original characters; never draw known characters, logos or album art.

## Talking to non-technical users

- Ask for: the audio file, and a synced lyrics file — "search the song on https://lrclib.net and
  download the synced lyrics (.lrc)". Without it you can still work (speech recognition, slower).
- Show, don't tell: send stills and short 720p previews rather than tables.
- Files in a chat may have a size limit (~30 MB): deliver a 720p version or split long videos.
- Rendering takes time: about 1 s of compute per second of 1080p video for the pixel style.
