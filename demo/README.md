# Demo song · 演示歌《纸飞机》

No song at hand, or just want to see the whole process first? Generate a free one:
手边没有歌、或者想先把流程走一遍？生成一首免版权的演示歌：

```bash
python demo/make_demo_song.py
# -> demo/paper_plane.wav  (46 s, an 8bit tune written by code)
# -> demo/paper_plane.lrc  (8 original lines, synced)
```

Then tell your AI: "Make an MV for demo/paper_plane.wav with demo/paper_plane.lrc, pixel style, don't stop."
然后对 AI 说："用 demo/paper_plane.wav 和 demo/paper_plane.lrc 做一支像素风 MV，不用停。"

The melody and the lyrics are original and part of this project (MIT) — you can post the result anywhere.
旋律和歌词都是原创的，随本项目以 MIT 许可发布，做出来的视频可以随便发。
