# 第 7 步自检清单

交付前逐条过一遍。每条后面是检查方法。

## 歌词与画面
- [ ] 每句歌词都有对应画面 —— 对照 `LYRIC_SHOTS.md`
- [ ] 重复的句子换了新画面 —— 同上，看"重复句"那几行
- [ ] 遮住内容要点，只看画面钩子，情绪和意思对得上 —— 自己看 `contact_sheet.py` 的拼图
- [ ] 全片只用一套比喻；没有浮在画面上的标签和对话气泡（场景里的招牌、日期、编号可以有）

## 人物
- [ ] **主角在每个镜头里都一眼看得清**，缩到手机大小也看得清 —— `shot_check.py` 的 `_phone.jpg`
- [ ] 五官、发型、衣服配色前后一致
- [ ] 情感镜头有表情（哭、笑、脸红、惊讶），不是一张平脸
- [ ] （v4）**造型**：没有椭圆身体、线条胳膊、头叠头；背影是单独画的；特写是专门画的半身像，不是放大的小人 —— 中间帧放大到 100% 看
- [ ] （v4）人物占画面高度：远景 10–15%，中景 ≤ 30% —— `shot_check.py` 的检查图上量

## 镜头与节奏
- [ ] 每个剪切点落在节拍上（开唱拍、重拍）—— `music.json` 里的 `line_beats`
- [ ] 按乐句切，平均 5–9 秒一镜；副歌至少一个 3 秒以上的长镜头
- [ ] 每个镜头里一直有东西在动 —— `metrics.py` 的镜头内动态 / 几乎不动的秒数
- [ ] （v4）景别配比：远景 25–35%、中景 35–45%、近 / 特 15–25%、插入镜头 ≥ 10%；同一景别不连用超过 2 镜 —— 数 `STORYBOARD.md`
- [ ] （v4）≥ 50% 的镜头有缓慢推拉、横移或升降
- [ ] 3–4 个核心场景反复出现，而不是每句一个新地方

## 光与色
- [ ] 每个夜景 / 暗场有可见光源和光晕（抒情歌）；甜歌白天保持明亮
- [ ] 色板切换落在情绪高点；信物的颜色全片一致，且是唯一的高饱和色
- [ ] 背景不留大片纯色，有纹理和小细节
- [ ] （v4）建筑有材质和至少 5 种构件；每个场景至少 2 件一眼认得的生活物件；前景 / 中景 / 背景三层都有东西

## 字幕安全区
- [ ] 有人声时，底部（横屏 170px / 竖屏 300px）没有界面文字、人脸、手部动作、信物 —— `subtitle_safe.py` 逐句 3 帧检查图
- [ ] 被挡住的元素往上挪，或整景上移 100–150px

## 技术
- [ ] 转场没有黑帧、跳帧
- [ ] 音画时长一致，首尾淡入淡出
- [ ] 1080p（或竖屏 1080×1920），yuv420p，能在手机上直接播放
- [ ] 没有任何地方出现 AI 写出的歌词原文

## 量化指标（参考值，不是及格线）
`python tools/review/metrics.py out/final.mp4 --mood moody|bright`，标 `look` 的项想清楚是不是有意为之。

## 丰富度（v4，规则 11）
`python tools/review/richness.py out/final.mp4`（有参考片加 `--ref 参考片.mp4`）。默认阈值：细节量 ≥ 5、颜色数 ≥ 30、有纹理区块 ≥ 50%、全片明暗起伏 ≥ 25、镜头推拉 + 横移 ≥ 50%；有参考片时取较高的那个。标 `LOW` 的项要返工。
