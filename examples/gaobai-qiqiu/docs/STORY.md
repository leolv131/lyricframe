# STORY：《告白气球》（周杰伦）

## 整体理解
- 轻快、甜的告白歌：一个男生在巴黎左岸约会、追女生，从被她说"不好追"，到最后她点头答应。
- 情绪一路往上，没有低谷。歌里现成的画面词很多：河边、咖啡、唇印、玫瑰、写错名字的卡片、被风吹走的气球、落叶、搞砸的约会、日记、香水、眼睛。

## 故事（一句话：**他准备了一只告白气球，整首歌都在等它"告白成功"**）
- 前奏：清晨巴黎，一只红色爱心气球升起；他在河边咖啡馆提前到，用汤勺照头发；她来了
- 主歌 1：第一次约会——咖啡洒了、杯沿唇印、花卡名字写错、气球被风吹走，飘成天上的笑脸
- 导歌 1：她表示"没那么容易"（难度五星、举"退"字牌），他不送贵重礼物，只送一片落叶；约会搞砸了两个人都在笑，镜头拉远成两个人的小星球
- 副歌 1：日历圈起的那天、方糖溅成爱心、她鼓腮又偷瞄、最后点头
- 间奏：他在河边小舞台上；夜里吹了 99 个气球，系在她窗外写着"明天见"
- 主歌 2 / 导歌 2：**同样的句子全部换新画面**（雨天、拉花、亲脸颊、名字写对了、一整串气球、九级台阶、落叶夹进日记、野餐遇雨、水晶球）
- 副歌 2：拍立得照片墙、棉花糖、鬼脸、瞳孔里的爱心
- 终副歌：恋爱日记、香水雾里的回忆泡泡、一整瓶星星、两杯咖啡搅成一杯 → 夜晚铁塔下单膝跪地举起红气球 → 她答应了，告白成功，烟花
- 谢幕：两人鞠躬，红幕布合上

## 角色与信物
| | 固定特征 |
|---|---|
| 他 | 短发、浅蓝衬衫、卡其裤 |
| 她 | 黑长发、奶白贝雷帽、粉色波点连衣裙 |
| **红色爱心气球** | 全片唯一的正红 `#ff3b5c`：告白的信物，也是"告白进度"的图标 |

## 一套比喻（视觉语法）
- 「告白进度」5 个小气球：每到一个情感节点亮一格，最后一格在她答应的那一拍亮起 → "告白成功！"
- v1 是右上角常驻；v3.1 改成只在 5 次 +1 前后出现约 3 秒（常驻界面会分散注意力）
- 不加歌词字幕；画面上的字只有招牌、卡片、清单这类道具字
