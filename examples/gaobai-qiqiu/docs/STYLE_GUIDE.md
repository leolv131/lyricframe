# STYLE_GUIDE：像素风 · 巴黎粉彩

- 工具包：`styles/pixel8bit`；320×180 画布，放大 6 倍输出 1920×1080，30fps；只按整像素运动
- 本片专用零件 `src/gbl.py`：原创简笔铁塔、奥斯曼式楼房、河与游船、咖啡馆（海军蓝条纹遮阳棚）、花店、红色爱心气球、告白进度、落叶、烟花
- 全彩，不做灰阶叙事；**红色只留给气球**
- 署名：片头片名下"原唱 · 周杰伦"，片尾 THANKS FOR WATCHING + "原唱 · 周杰伦"

## v3.1 重做时改了什么（`src/gb2.py`）
- **甜歌不压暗**：白天保持亮粉彩，只给黄昏和夜景布光（`relight()`，人物保底亮度 0.55）
- **每个镜头加环境动态**：云（`clouds`）、花瓣（`drift_petals`）、小气球（`mini_balloons`）、水面闪光（`sparkle_water`）
- **按乐句合并镜头**：56 镜 → 38 镜
- 告白进度只在 5 个 +1 时刻前后出现 3 秒（`hud_moment`）
- 画面上的字砍掉大部分，只留片名、"告白成功！"和署名
