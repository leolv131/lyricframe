# STORY：《蝴蝶》

## 一、整体理解

- **谁对谁说**：一个跌到谷底的人，对一直没放弃他的"你"说。原曲收在陶喆 2005 年的《太美丽》，网上常见两种读法：唱给爱人，或唱给信仰里的"救赎"。MV 取**最具体的读法：唱给一个人**，"救赎"藏在故事里，不另造象征
- **情绪线**：被丢下（灰）→ 坠落 → 见到你（第一次有颜色）→ 还是逃避、躲着你 → 你不放弃 → 站起来 → 好的坏的一起扛 → 新生、感激（全彩）。**一路往上走，没有回落**
- **本身就有画面的词**：被丢掉、伤兵、荒野、隐形、迷宫、氧气、天晴、**蝴蝶、废墟**、倒下 / 站起、眼睛、冷
- **抽象的句子**（要发明画面）：怀疑自己存不存在、觉得配不上被珍惜、感激、重新开始、面对自己（第 3、17、18、23–25、36–38 句一带）

## 二、故事（一句话立意：**他以为自己是一片废墟，她一直把他当成一个还没破的茧**）

**他**——小伍，开了一家很小的花店"小伍花店"。店撑不下去关了，老街又赶上拆迁，花店变成了一片**废墟**。他觉得自己就是被世界丢掉的那个，越来越没存在感，躲在出租屋里谁也不见。

**她**——花店以前的老顾客、也是他的女朋友阿蝶。头上别着一枚**蓝色蝴蝶发夹**。他躲她、找借口、不回消息；她每天把饭挂在门把手上，在门上贴便利贴，从废墟里把店里唯一活下来的那盆小苗捡回来，天天浇水。

那盆小苗的叶子上挂着一个**茧**。

- 副歌 1：她敲开门，伞下是全片第一块有颜色的地方 → 废墟上第一次飞过一只蓝蝴蝶
- 主歌 2：他还是逃（迷宫、借口、躲在被子里），她没死心（便利贴 DAY 1 → DAY 47、铁盒里珍藏着他送过的歪歪扭扭的干花）
- 副歌 2：**茧破了，蓝蝴蝶从那盆小苗上飞出来**；废墟砖缝开花；他从自己倒下的那个人形轮廓里站起来
- 桥段：她的眼睛里映出完整的他；她把他的旧围裙递回给他（相信他还能开店）→ 他重生；下雪天共用一条围巾；她背着喝醉的他；最好和最坏的日子都一起过
- 终副歌：全城放晴、彩虹；上百只蓝蝴蝶飞过清理好的废墟；**新的小伍花店在原址开张**；他把感激和一枚蓝蝴蝶戒指交给她；他心里有一间小屋，只有一把椅子，是她的专座
- 尾奏：两人在花店门口收摊，片尾 STAFF

## 三、视觉语法（常驻，不靠解释）

1. **存在感 = 他身上的颜色**（全片常驻）
   - 被忽视时：他变**灰、半透明，轮廓变成虚线**，路人能从他身上穿过去、自动门对他不开
   - 她靠近时：颜色从接触的地方流回他身上
   - 观众不用解释就能看懂："他快消失了"/"他又回来了"
2. **她 = 颜色的来源**：她走到哪，哪里就有一圈暖色；她的伞下不下雨
3. **蓝蝴蝶 = 希望**：每次出现都和她有关，越来越多（1 只 → 破茧 → 一群）
4. **天气 = 心情**：他头顶常驻一朵小乌云（低谷时下雨），副歌 2 被她的伞戳破
5. **片头片尾**：片头 STAFF 小字叠在开场雨夜里；片名《蝴蝶》在 0:45 第一只蝴蝶掠过废墟时出现

> 和网上另一支同名 AI MV 区分开：那支用的是游戏界面语法（HP、GAME OVER、存档、A/B 门）。这版**不用游戏 UI**，改用"颜色 = 存在感"，故事落在一家花店上。
