# STYLE_GUIDE：像素风 · 不加游戏界面

## 定调
- **像素风**：320×180 画布，放大 6 倍输出 1920×1080，30fps。只按整像素移动，"推近"靠换更大尺寸的画，不做平滑缩放
- **不加游戏界面**（不放 HP、STAGE、GAME OVER）；全片的常驻规则是"**颜色 = 存在感**"
- 工具包：`styles/pixel8bit`（`hd.py` 里有本片做出来的色板、蓝蝴蝶、雨、伞、隐形合成、废墟零件，后来并进了工具包）

## 色板（守住）
| 用在 | 怎么做 |
|---|---|
| 谷底（主歌、导歌） | 整帧量化到 9 级雨灰蓝 `GRAY_RAMP` + 4×4 有序抖动 |
| 废墟黄昏（镜 17 等） | 9 级暮色灰紫 `DUSK_RAMP` |
| 她身边 | `radial_keep()` 画一圈"保留原色"的区域 + 奶油色暖光；圈的边缘用抖动过渡 |
| 副歌 2 / 桥段 / 终副歌 | 圈越来越大，到 3:12.3 整帧不再量化（全彩） |
| 信物 | 闪蝶蓝 `#2f8cff` / 高光 `#8fd6ff`，**量化时永远保留**（`is_blue`），全片只有它是高饱和蓝 |

## "颜色 = 存在感"怎么画（`ghost()`）
- 他被忽视时：画在单独图层，按有序抖动只露出一部分像素（alpha 0.4–0.65），外轮廓是会爬动的虚线
- 她靠近时：`keep` 区域里的像素恢复颜色、恢复实体 → 颜色从接触的地方流回他身上
- 她和她的伞永远是彩色

## 角色（见 `样张/角色设定.png`）
- **小伍**：三撮翘头发、灰卫衣、深蓝牛仔裤、左脸创可贴；重生后系绿色花店围裙（胸口绣一朵小花）
- **阿蝶**：齐肩波波头 + 平刘海、右侧蓝蝴蝶发夹、奶白毛衣、浅蓝牛仔裤、暖黄伞
- 尺寸：远景头高 14、中景 26–30、近景 44、特写 ≥ 80（头高 ≥ 36 自动用精细五官：虹膜、高光、泪光、腮红）
- 表情：各 8 种（平静 / 低落 / 含泪 / 哭 / 惊讶 / 微笑 / 开心 / 脸红；她多一个担心）；头顶符号 ? ! ❤ 汗 ♪ ✦

## 蓝蝴蝶
- 闪蝶形状（前翅大、后翅小、黑翅缘、白点）；4 帧扇动；尺寸 S1（远景）/ S2 / S3 / S5（特写）
- 飞行时身后拖一条淡蓝亮线（`trail()`）

## 场景规范
- 三层：远（楼群剪影 + 亮窗）/ 中（墙、栏杆、废墟）/ 前（水洼、碎砖、雨）
- 背景至少一样东西在动：雨、晾衣、水洼涟漪、蝴蝶
- 雨：斜 0.3、1 像素宽、3–5 像素长，落地溅点；伞下不下雨
- 字幕安全区：有人声时，底部 170px（画布 28px）不放文字和关键道具

## 署名
片头（镜 01 左上角小字淡入）+ 片尾 STAFF + 封面：`原唱 · 陶喆`；片尾 THANKS FOR WATCHING，用同一套像素字体

## 美术基准对比（网上同名 AI MV vs 我们的样张）
| | 同名 AI MV | 我们的样张 | 制作时补 |
|---|---|---|---|
| 天空 / 城市 | 网点渐变很细，楼有破损轮廓 | 色带 + 抖动，楼偏规整 | 楼加破洞、空调外机、招牌 |
| 角色 | 很小，靠剪影 | Q 版大头，能做表情特写 | 保持我们的优势 |
| 色彩 | 每段整体换色 | 只在她身边一圈恢复颜色 | 这是我们的叙事核心，保持 |
| 废墟碎砖 | — | 偏"一坨"，层次不够 | 砖块再拉开明暗、加钢筋和杂草 |
